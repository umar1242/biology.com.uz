# 11. Эксплуатация

## Деплой

```bash
./scripts/deploy.sh
```

Скрипт делает два шага в правильном порядке: пересобирает и поднимает
контейнеры, затем применяет миграции. Ручной второй шаг — тот, который легко
забыть, и тогда новый код молча идёт по старой схеме. Ошибка миграции здесь
фатальна: интерактивный деплой должен остановиться и показать её.

Отдельные скрипты: `start-stack.sh` для загрузки, `backup-db.sh` и
`restore-db.sh` для копий базы.

## Миграции

```bash
npm run db:migrate            # применить всё, чего ещё нет
npm run db:generate           # сгенерировать по изменениям схемы
```

Перед боевой базой миграция проигрывается с нуля по всей цепочке на отдельной
базе. Это ловит ошибки, невидимые на своей машине: например, попытку
использовать новую метку перечисления в той же транзакции, где она добавлена.

## Резервные копии

`scripts/backup-db.sh` кладёт дамп в `backups/`. Каталог в `.gitignore`: там
персональные данные учеников, и в публичный репозиторий им нельзя.

Ограничения текущей схемы: копии не шифруются и лежат на той же машине.

## Тесты

### Модульные

43 теста на чистых функциях, запуск `npm run test:unit`. Покрыты: структура и
подсчёт баллов сертификата, пробный период, шаблон уведомлений, движок Раша.

Тесты Раша — на восстановлении параметров: единственный корректный способ
проверить оценщик. Они сразу нашли настоящую ошибку знака, из-за которой
оценки расходились на 97 логитов.

### HTTP

Три набора против живого сервера и настоящей базы, 256 проверок:

| Набор | Проверок | О чём |
|---|---|---|
| `test/e2e-staff.sh` | 99 | вход, курсы, модули, уроки, ДЗ, доступ, помощники, настройки |
| `test/e2e-student.sh` | 41 | вход по initData, анкета как шлюз, изоляция ученика |
| `test/e2e-cert-exam.sh` | 116 | вариант, ключ, сдача, проверка, банк заданий |

Запуск: `npm run test:api` или по одному через `test:api:staff`,
`test:api:student`, `test:api:cert`.

Окружение задаётся переменными и целиком описано в `test/lib.sh`:

| Переменная | Зачем |
|---|---|
| `API_BASE` | адрес API |
| `DATABASE_URL` | прямое подключение (так работает CI) |
| `PG_CONTAINER`, `PG_USER`, `PG_DB` | доступ через `docker exec`, локальный вариант |
| `TELEGRAM_BOT_TOKEN` | подпись initData |

Токен здесь — не доступ куда-либо, а ключ HMAC. Он обязан лишь совпадать с
тем, что проверяет сервер, поэтому в CI стоит заведомо поддельный, а проверка
подписи остаётся настоящей.

Учётные записи для тестов создаёт `npm run seed:e2e` под защитой
`E2E_SEED=yes`. Самозаписи в платформе нет по устройству, поэтому на чистой
базе они появиться не могут.

Вместо Телеграма отвечает `test/telegram-stub.mjs`. Он нужен не ради вежливости
к чужому API: часть эндпоинтов ходит в Bot API прямо внутри запроса (диплинку
нужен `getMe`, записи на курс — `createChatInviteLink`), и без ответа эти
сценарии не выполнить вовсе.

## CI

`.github/workflows/ci.yml`, два задания на каждый push и pull request.

**checks** — без базы и без секретов: типы, модульные тесты, сборка API,
сборка панели и мини-аппа.

**e2e** — поднимает Postgres, прогоняет миграции, создаёт учётные записи,
запускает заглушку Телеграма и настоящий сервер, гоняет три набора. Секретов
не требует.

Это единственное место, которое ловит поломку в проверке прав: модульные тесты
покрывают чистые функции, а маршруты больше ничем не проверяются.

## Наблюдение

Логи структурированные (pino), включая ошибки фоновых задач: сбой задачи
попадает в тот же поток, что и остальные логи сервера, а не в отдельный
`console.error`.

`GET /health` выполняет настоящий `SELECT 1` к базе, а не отвечает статикой.
На нём же построена проверка здоровья контейнера.

## Что стоит улучшить

**Проглоченные ошибки.** В API около полутора десятков мест, где сбой Телеграма
превращается в `false` и исчезает. Одно из них закрыто уведомлением о неудачном
приглашении, остальные молчат.

**Нет повторов у исходящих сообщений.** Разовое событие, не доставленное в
момент сбоя Телеграма, потеряно навсегда. Периодические сводки переживут сбой
на следующем проходе, разовые — нет. Очередь с повтором была бы следующим
разумным шагом.

**Копия за пределами машины.** Сейчас дампы лежат там же, где база.
