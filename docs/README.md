# Документация платформы

Описание того, как устроена платформа онлайн-курсов biolog.com.uz: от записи
ученика до калибровки заданий по модели Раша.

Документы написаны по коду, а не по замыслу. Если в тексте расходится с
репозиторием, прав репозиторий — пришлите расхождение, поправим.
